## 10-Point Adversarial Audit Checklist (Must Verify Every Item)

### Gate 1: Completeness & Compilation Hygiene
- [ ] All 4 required files exist in full (`firmware/platformio.ini`, `firmware/src/main.cpp`, `host/requirements.txt`, `host/host_bridge.py`).
- [ ] **Zero stubs/truncation:** Scan for `TODO`, `FIXME`, `pass`, `...`, `// rest of code`, or placeholder comments. Any occurrence = automatic `REJECTED`.
- [ ] `platformio.ini` targets `esp32-s3-devkitc-1` (or `m5stack-cores3`) with `M5Unified` and `ArduinoJson` (`7.x`) pinned, plus `-DBOARD_HAS_PSRAM` / USB-CDC flags configured so `Serial` routes over USB-C at `921600` baud.

### Gate 2: ESP32-S3 Half-Duplex I2S Handoff (`main.cpp`)
- [ ] On **HOLD TO SPEAK press**: `M5.Speaker.stop()` and `M5.Speaker.end()` MUST complete **before** `M5.Mic.begin()` is called.
- [ ] On **HOLD TO SPEAK release**: `M5.Mic.end()` MUST complete **before** `M5.Speaker.begin()` is called.
- [ ] Verify `M5.Mic` and `M5.Speaker` are both explicitly configured to `sample_rate = 24000` (24 kHz mono 16-bit PCM).

### Gate 3: Binary Framing & Ring-Buffer Safety (`main.cpp` <-> `host_bridge.py`)
- [ ] Packet header is strictly `[0xAA, MSG_TYPE, LEN_HI, LEN_LO, PAYLOAD]` (big-endian `uint16` length).
- [ ] **Sync Recovery:** If a byte is dropped or serial starts mid-stream, the parser scans forward for `0xAA` and validates `LEN <= MAX_PACKET_SIZE` rather than hanging forever or overflowing a static buffer.
- [ ] **Heap Safety:** `main.cpp` does NOT allocate dynamic `String` or `new` buffers inside the `loop()` audio read/write hot path (uses fixed static ring/DMA buffers).

### Gate 4: `<50 ms` `LIVE SILENT` & Mode Cutoffs (`main.cpp` & `host_bridge.py`)
- [ ] Tapping `LIVE SILENT` (Touch Zone 2) or switching to `PERFORMANCE` mode immediately:
  1. Sets `speak_back = false` locally on the ESP32-S3.
  2. Calls `M5.Speaker.stop()` on the very next `M5.update()` tick (draining/flushing any queued `0x02` PCM chunks).
  3. Drops incoming `0x02` audio packets while `speak_back == false` so buffered serial bytes don't play after mute.
  4. Sends a `0x03` JSON state sync packet to `host_bridge.py` (`{"speak_back": false}`) and triggers `response.cancel` on OpenAI Realtime if a response is in flight.

### Gate 5: USB Serial Auto-Discovery & Non-Blocking I/O (`host_bridge.py`)
- [ ] Auto-discovers the macOS serial port by scanning `serial.tools.list_ports.comports()` for Espressif VID `0x303A` (with clean error message if unplugged, never hardcoded `/dev/cu.usbmodem...`).
- [ ] Serial reads/writes never block the `asyncio` event loop (uses `pyserial-asyncio-fast` or dedicated thread/executor queues) so MIDI tick scheduling never jitters during audio streaming.

### Gate 6: OpenAI Realtime API & Manual Push-to-Talk (`host_bridge.py`)
- [ ] Uses `async with client.realtime.connect(model="gpt-realtime") as connection:` (not deprecated `client.beta.realtime`).
- [ ] Session configures `input_audio_format="pcm16"`, `output_audio_format="pcm16"`, `turn_detection=None` (manual push-to-talk), and registers all **7 required tools** (`set_production_mode`, `write_chord_progression`, `extract_bassline`, `write_drum_pattern`, `set_channel_gain`, `arrange_sections`, `set_talkback`).
- [ ] On `ptt_active: false` (button release), explicitly sends `input_audio_buffer.commit` followed by `response.create`.
- [ ] Tool execution loop returns `conversation.item.create` (`function_call_output`) and triggers `response.create` so Lick-Lubin speaks his 1-line Rick Rubin critique (when `speak_back == True`).

### Gate 7: Drift-Free `perf_counter()` CoreMIDI Sequencer (`host_bridge.py`)
- [ ] Opens `IAC Driver Bus 1` via `python-rtmidi` (`rtmidi.MidiOut()`), raising a clear setup instruction if IAC Driver is disabled in Audio MIDI Setup.
- [ ] Uses monotonic `time.perf_counter()` target scheduling (`target_time = start_time + tick_idx * (60.0 / 101.0 / 4.0)`)—NEVER cumulative `await asyncio.sleep(0.14851)`.
- [ ] Maps MIDI channels strictly per TDD: `Ch 1 (0x90/0x80)` = Piano, `Ch 2 (0x91/0x81)` = Bass 1, `Ch 3 (0x92/0x82)` = Drums (`C5=60` Kick, `D5=62` Snare, `F#5=66` Hat).

### Gate 8: Stuck-Note & CC Routing Guarantees (`host_bridge.py`)
- [ ] Sends `CC 123` (`[0xB0 | ch, 123, 0]`) + explicit active `note_off`s whenever a pattern is overwritten, a channel is muted (`CC 30–33`), or playback stops.
- [ ] `set_channel_gain` maps cleanly to `CC 20–23` (`0–127`) and `CC 30–33` (`0` = mute, `127` = unmute) on Channel 1 (`0xB0`).

### Gate 9: Act II -> Act III Atomic `PERFORMANCE MODE` Handoff (`host_bridge.py`)

  4. Plays the exact arranged bar count (e.g., `16 bars = 256 ticks = 38.02s` at `101 BPM`) and terminates cleanly with `CC 123` on all channels on the final downbeat.

### Gate 10: Musical Blueprint Integrity (`101 BPM`, `D Major`)
